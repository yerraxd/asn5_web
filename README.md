## Description
Three pages with JavaScript tasks. Pages are connected with a Bootstrap navbar.

## Pages
- `index.html` (Tasks 1-4): console output and variables, change text by button, night mode and font size, add/remove list items
- `task2.html` (Tasks 5-7): mouse events (hover box), keyboard events (live input), calculator
- `task3.html` (Task 8): to-do list with add, delete and strike-through for completed tasks

## Files
- `index.html`, `style.css`, `index.js`
- `task2.html`, `style2.css`, `index2.js`
- `task3.html`, `style3.css`, `index3.js`

## Technologies
HTML, CSS, JavaScript, Bootstrap 5 (CDN)

## How to run
Open page `index.html` in a browser. Use the navbar to switch between pages.
